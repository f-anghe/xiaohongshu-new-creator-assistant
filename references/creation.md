# 创作模块

## 输入

- 已确认的 `profile_id` 和账号主页资料；
- 用户本次输入的作品主题；
- 当前有效账号创作地图；
- 用户确认后的本篇作品创作上下文；
- 可选文字素材；
- 可选图片解析描述。图片只用于提取内容信息，不直接作为发布素材；
- 联网检索快照和本地知识检索快照；
- 可选正文目标字数 `body_length_target`，取值为 1–800；未填写时使用 800 字上限；可选创作类型 `content_type`：`method`、`artifact` 或 `hybrid`。

## 流程

1. 用户只需用一句话输入本篇想写的主题；
2. 复用自适应创作思路深挖规则，按主题形成内容类型候选，并补齐作品目标、读者收获、内容重点、素材来源、表达结构和文风；不要求用户直接填写内部蓝图字段；
3. 用户确认创作蓝图后，自动执行联网公开资料检索和当前账号知识检索；蓝图保存内容类型候选/置信度、条件字段状态、内容结构、素材来源和格式约束；
4. 生成一个完整主版本，不生成图片；
5. 正文先按目标字数重组、压缩和凝练，不能生成后截断；`content_type=method` 时不自动增加独立的产物示例模块，除非用户明确要求；
6. 按“封面方案 → 配图建议 → 标题 → 正文”的顺序展示主作品；
7. 展示公开来源、产品知识、账号私有知识、用户素材和模型推测的边界；
8. 用户可以编辑全部文本字段并一键复制；表现层和结构层修改复用原检索快照，事实层修改或新增素材时重新确认上下文并生成新的检索快照；
9. 保存创作记录和草稿版本，但不自动写入学习案例或账号知识。

## 输出

- 封面文字与信息层级方案；
- 每张图片的画面、构图、文字和信息任务建议；
- 标题；
- 完整正文；
- 话题和关键词；
- 公开来源和知识库引用；
- 事实来源、未知项、不确定性和风险提示；
- 可编辑字段清单。

不得输出原文、Diff、采用状态或固定曝光/点赞/涨粉承诺。

`content_type=method` 时，正文应聚焦方法、步骤和注意事项；除非用户明确要求，不得追加“简版 PRD 示例”等独立产物模块。正文有效字数按去除换行和首尾空格后的 Unicode 字符计数，中文、英文、数字和标点均计入，不能超过 800 字或用户指定的更低目标。

## 素材与真实性

- 用户素材只能作为用户提供事实使用；
- 图片先解析为内容描述，再进入生成上下文；
- 联网来源必须有URL、标题和检索时间；
- 模型不得虚构用户经历、产品功效、数据、来源或专业资质；
- 高风险主题只能生成有来源的科普或信息整理，并降低确定性、标注适用范围和专业核验要求。
