# 小红书新手运营 AI 助手｜产品初始知识库

## 1. 知识库定位与三层结构

本知识库只服务“优化 Demo”，用于诊断历史图文内容、提出内容改动建议、给出待验证指标和说明证据边界。它不保存账号个人数据、创作地图或私有案例，也不负责实验创建、结果比较和案例沉淀。

知识库统一按以下三层组织：

```text
第一层：优化目标
├─ 高点击率
├─ 高点赞率
└─ 高收藏率

第二层：分析维度
├─ 用户心理
├─ 封面设计
├─ 标题设计
├─ 内容方法
├─ 图文结构
└─ 搜索与长尾

第三层：具体知识单元
├─ 适用问题
├─ 具体动作
├─ 作用机制
├─ 适用内容
├─ 证据等级
└─ 限制与验证方法
```

每条知识单元都必须回答：解决什么问题、改哪里、为什么可能有效、适合什么内容、依据有多强、如何验证及有什么限制。这里的“高点击率/高点赞率/高收藏率”是优化目标，不是效果保证。

## 2. 使用规则与证据边界

### 2.1 来源优先级

1. 用户确认的账号创作地图；
2. 当前账号用户确认的私有案例；
3. 本产品初始知识库；
4. 用户当前对作品的明确要求。

更具体、更新且经用户确认的账号信息优先于通用知识。不同指标的知识不能互相替代：高点击知识不能冒充高收藏知识，高点赞知识也不能直接证明收藏价值。

### 2.2 证据等级

- **原则**：用于解释内容设计机制，不等于平台公开算法规则。
- **方法**：可作为内容设计和分析建议，需要结合账号场景。
- **假设**：只能作为待验证方向，不能表达为确定有效。

模型必须区分已有依据、合理推测和待验证假设，不能把相关性写成因果，也不能承诺曝光、点赞或涨粉。

### 2.3 三个优化目标

- **高点击率**：用户看到封面和标题后愿意点击，重点检查选题、人群、场景、问题、结果和理解成本。
- **高点赞率**：用户浏览后产生认同和表达，重点检查内容兑现、具体观点、情绪价值和身份共鸣。
- **高收藏率**：用户认为未来还要复习或使用，重点检查清单、步骤、模板、判断标准、适用范围和长期使用价值。

## 3. 第一层：高点击率

高点击率的核心不是制造夸张，而是让目标用户快速理解“这和我有关、可能解决我的问题、值得继续看”。以下知识按第二层分析维度组织。

### 3.1 用户心理

**知识单元：降低点击判断成本**

- **适用问题**：曝光有了但点击率低；用户看不懂主题或无法判断是否与自己有关。
- **具体动作**：在封面、标题和开头明确目标人群、使用场景、问题、结果或信息差；删除无关装饰和抽象表达。
- **作用机制**：相关性、适度信息缺口和加工流畅性可能降低用户继续处理信息的成本。
- **适用内容**：教程、攻略、问题排查、对比、清单和场景解决方案。
- **证据等级**：方法。
- **限制与验证方法**：不能保证流量；发布后观察封面点击率，并结合曝光量、账号阶段和样本量判断。

### 3.2 封面设计

**知识单元：突出主题、结果与视觉主体**

- **适用问题**：曝光较高但封面点击率低；封面信息拥挤、主题不清或画面与正文不一致。
- **具体动作**：突出一个视觉主体，并用少量可读文字表达目标人群、场景、结果、步骤、清单、数量或对比。
- **作用机制**：清晰的视觉层级和可读信息可能帮助用户快速完成主题理解。
- **适用内容**：教程、清单、对比、测评、案例复盘和场景方案。
- **证据等级**：方法。
- **限制与验证方法**：不能用无关画面骗取点击；发布后观察封面点击率，不单独以曝光判断封面有效。

### 3.3 标题设计

**知识单元：搜索词与点击理由组合**

- **适用问题**：标题无法说明人群、问题或结果；关键词堆砌或承诺与正文不一致。
- **具体动作**：使用“搜索词 + 人群/场景 + 问题/结果”组织标题，保留自然表达并兑现标题承诺。
- **作用机制**：具体词汇和明确承诺可能降低点击前的理解成本。
- **适用内容**：攻略、方法、问题排查、对比、测评和清单。
- **证据等级**：方法。
- **限制与验证方法**：不得绝对化、虚假承诺或近似仿写爆款标题；发布后观察点击率和点击后的内容兑现情况。

### 3.4 搜索与长尾

**知识单元：主题词、人群词、场景词和问题词组合**

- **适用问题**：用户搜索意图与标题、正文不匹配，或内容只有宽泛主题没有具体场景。
- **具体动作**：围绕真实问题组合主题词、人群词、场景词和问题/结果词，自然分布在标题、正文和图片信息中。
- **作用机制**：更具体的词组可能提高意图匹配和点击判断效率。
- **适用内容**：搜索型教程、城市/身份/预算/时间等长尾场景内容。
- **证据等级**：方法。
- **限制与验证方法**：不重复堆砌关键词、不使用无关热点；发布后观察搜索来源和点击率。

## 4. 第一层：高点赞率

高点赞率的核心是让用户感到“有价值、被说中、我认同或我愿意表达”。高点击不等于高点赞，正文必须兑现点击承诺。

### 4.1 用户心理

**知识单元：建立身份共鸣与具体体验**

- **适用问题**：点击率不低但点赞率低；内容有信息却没有认同感。
- **具体动作**：补充真实场景、具体经历、身份处境、个人判断和可共鸣的细节。
- **作用机制**：自我参照、社会认同和情绪共鸣可能增强表达意愿。
- **适用内容**：经历、成长、观点、生活记录、反差和经验复盘。
- **证据等级**：方法。
- **限制与验证方法**：不能编造经历或强行煽情；发布后观察点赞率及评论中的身份共鸣信号。

### 4.2 封面设计

**知识单元：让用户产生情绪或身份代入**

- **适用问题**：用户愿意点击，但封面没有形成情绪期待或身份识别。
- **具体动作**：使用真实人物、自然表情、生活场景、代表某类人的视觉符号或有解释空间的反差画面。
- **作用机制**：熟悉的身份线索和情绪画面可能帮助用户代入。
- **适用内容**：生活记录、成长故事、观点、体验和情绪表达。
- **证据等级**：方法。
- **限制与验证方法**：画面必须与正文同一核心；发布后观察点赞率，不能把情绪刺激写成必然有效。

### 4.3 标题设计

**知识单元：经历、观点与身份认同组合**

- **适用问题**：标题能带来点击，但没有表达“为什么值得认同”。
- **具体动作**：使用“经历 + 感受/判断”“身份 + 共鸣”“反差 + 观点”等自然组合。
- **作用机制**：具体经历和个人判断可能让目标用户完成自我参照。
- **适用内容**：成长、职业、生活方式、经验复盘和观点表达。
- **证据等级**：方法。
- **限制与验证方法**：不能使用空泛鸡汤或夸大冲突；发布后观察点赞率和评论中的观点回应。

### 4.4 内容方法

**知识单元：观点兑现与真实细节**

- **适用问题**：正文只有结论或知识罗列，缺少具体观点、证据和情绪落点。
- **具体动作**：用事件、动作、对话或案例支撑观点，说明个人判断，并留出用户表达空间。
- **作用机制**：具体细节和清晰判断可能增强真实感、认同感和表达意愿。
- **适用内容**：观点、经历、案例复盘、成长和生活观察。
- **证据等级**：方法。
- **限制与验证方法**：不得把个人经验包装成普遍结论；发布后观察点赞率和评论质量。

### 4.5 图文结构

**知识单元：场景—冲突—细节—观点的叙事结构**

- **适用问题**：图文信息堆叠，用户看完没有情绪变化或观点落点。
- **具体动作**：按人物/场景、冲突或反差、生活细节、情绪变化、个人观点组织图片和文字。
- **作用机制**：连续叙事可能帮助用户理解经历并产生代入。
- **适用内容**：故事、生活记录、成长、职业和情绪表达。
- **证据等级**：方法。
- **限制与验证方法**：避免强行索取互动；发布后观察点赞率及评论是否回应核心观点。

### 4.6 搜索与长尾

**知识单元：用具体身份和场景承接共鸣**

- **适用问题**：内容有观点但目标人群不明确，搜索词无法体现用户处境。
- **具体动作**：在自然表达中加入身份、生活状态、具体场景和问题词，让用户看见“这说的是我”。
- **作用机制**：身份和场景匹配可能增强自我参照和群体认同。
- **适用内容**：职业、城市、生活阶段、能力差异和具体处境内容。
- **证据等级**：方法。
- **限制与验证方法**：不为了关键词牺牲真实表达；发布后观察点赞率和评论中的人群匹配。

## 5. 第一层：高收藏率

高收藏率的核心是让用户未来还会回来使用。收藏导向不等于堆砌信息，也不代表收藏率一定提升。

### 5.1 用户心理

**知识单元：提供未来可复用的判断支持**

- **适用问题**：点击率或点赞率尚可，但收藏率低；内容有观点却没有复习理由。
- **具体动作**：补充清单、步骤、模板、判断标准、适用范围、限制条件和复查提示。
- **作用机制**：可执行、可复查的信息可能形成长期使用价值。
- **适用内容**：教程、攻略、避坑、框架、对比和决策内容。
- **证据等级**：方法。
- **限制与验证方法**：只保留与用户问题相关的信息；发布后观察收藏率和收藏后回访/使用反馈。

### 5.2 封面设计

**知识单元：让用户一眼识别可保存价值**

- **适用问题**：内容本身有用，但封面没有说明清单、步骤、模板或框架价值。
- **具体动作**：在封面明确“清单/步骤/模板/框架/避坑”等内容任务，并保持信息层级清晰。
- **作用机制**：用户提前知道未来用途，可能更容易形成保存意愿。
- **适用内容**：教程、清单、流程、对比、框架和复盘。
- **证据等级**：方法。
- **限制与验证方法**：封面承诺必须由正文兑现；发布后观察收藏率，不能只用“可收藏”字样替代内容价值。

### 5.3 标题设计

**知识单元：明确可复习内容与适用场景**

- **适用问题**：标题能带来点击，但没有说明内容以后何时有用。
- **具体动作**：使用“人群/场景 + 问题 + 清单/步骤/判断标准/模板”等自然表达。
- **作用机制**：具体使用场景和内容形式可能帮助用户预判复用价值。
- **适用内容**：攻略、避坑、对比、工具、流程和决策框架。
- **证据等级**：方法。
- **限制与验证方法**：不得把普通观点包装成清单或模板；发布后观察收藏率和正文使用反馈。

### 5.4 内容方法

**知识单元：问题—标准—步骤—适用范围结构**

- **适用问题**：正文只有抽象观点或介绍，缺少可执行、可复查的信息。
- **具体动作**：按用户问题、判断标准、操作步骤、示例/结果、适用范围、限制与复查提示组织内容。
- **作用机制**：具体且有边界的结构可能提高未来复习和实际使用价值。
- **适用内容**：教程、清单、模板、框架、避坑、对比和案例复盘。
- **证据等级**：方法。
- **限制与验证方法**：不能为了收藏堆砌无关信息；发布后观察收藏率，并结合评论中的实际使用反馈。

### 5.5 图文结构

**知识单元：一页一个信息任务**

- **适用问题**：内容有价值但难以查找，图片文字混杂或一页信息过载。
- **具体动作**：将问题、标准、步骤、示例、限制分别组织到清晰页面；使用标题、数字、对比和留白建立层级。
- **作用机制**：可定位、可扫描的结构可能降低未来复习成本。
- **适用内容**：多步骤教程、清单、流程、对比、框架和复盘。
- **证据等级**：方法。
- **限制与验证方法**：不能为分页面而拆散逻辑；发布后观察收藏率及用户对具体页面的反馈。

### 5.6 搜索与长尾

**知识单元：让用户能按未来问题找回内容**

- **适用问题**：内容有用但标题和正文使用宽泛词，用户以后难以搜索或回忆。
- **具体动作**：自然加入主题词、人群词、场景词、问题词、结果词和必要的工具/品类词。
- **作用机制**：具体长尾表达可能提高内容与未来检索需求的匹配度。
- **适用内容**：工具教程、职业问题、城市/预算/时间限制和具体决策场景。
- **证据等级**：方法。
- **限制与验证方法**：不重复堆砌关键词；发布后观察搜索来源、收藏率和用户是否能复述使用场景。

## 6. 跨目标边界与验证说明

### 6.1 诊断规则

- 曝光高、点击率低：优先检查高点击率下的用户心理、封面、标题和搜索知识。
- 点击率高、点赞率低：优先检查高点赞率下的内容兑现、观点、身份和叙事知识。
- 点击率高、收藏率低：优先检查高收藏率下的清单、步骤、标准、模板和复习结构。
- 点赞率高、收藏率低：说明可能有共鸣但不便于复用，应优先补充结构化方法。
- 收藏率高、点赞率低：说明可能实用但缺少观点或身份认同，应补充高点赞率相关知识并标记待验证。
- 数据不足、样本量小或多个位置同时变化：只能形成待验证假设，不得生成确定性结论。

### 6.2 优化 Demo 输出要求

每项主要改动必须形成以下映射：

```text
优化目标 → 分析维度 → 适用问题 → 具体动作 → 采用知识 → 建议验证指标
```

优化 Demo 可以输出“建议发布后验证收藏率”等指标建议，但不设计或执行实验。实验流程、结果比较和用户确认后的真实案例沉淀由现有实验反馈系统负责。

### 6.3 平台与安全边界

本知识库只服务小红书图文内容，不代表平台完整推荐算法，也不承诺曝光、点赞或涨粉。不得提供刷量、刷赞、虚假互动、搬运、抄袭、规避审核或制造虚假数据的建议。涉及健康、医疗、财务、法律等高风险主题时，应降低确定性并建议核验专业来源。
