# 公共规则

## 服务边界

- 只处理小红书图文内容，不处理视频或其他平台内容。
- 只服务当前 `profile_id`，不得跨账号读取、泄露或复用账号私有知识。
- 服务对象为所有小红书图文账号，粉丝量只作为账号资料字段，不作为服务准入或只读门槛。
- 不承诺固定曝光、点赞或涨粉结果。

## 资料准入门禁

- 新账号启动建档时的最小材料是：账号主页截图、单篇作品截图（多图需完整上传）、该作品对应的笔记数据截图；进入“创作”时先检查账号主页历史记录：无记录时最小材料是账号主页截图并完成确认，有记录时用户最小只需提交本篇主题。内部调用字段不是用户前置提交要求。
- 资料识别前不得要求用户提前填写账号定位、目标人群、作品目标、正文转写或其他内部字段；识别后仅针对明确缺口补问。
- 主页截图中的小红书 ID 是后续流程的必需主键；无法可靠识别时必须立即阻断。
- ID 无法识别时只提示重新上传主页截图，不要求用户继续提交作品截图或笔记数据截图。
- 在 ID 成功识别前，不得进入服务范围校验、建档、创作思路深挖、RAG 或优化 Demo。
- 作品截图必须覆盖该作品的全部图片；图片中的文字执行 OCR，纯图像执行视觉理解，标题和正文由截图识别或用户补充确认。
- 优化 Demo 入口必须先收齐作品截图、对应笔记数据截图和本轮优化目标；缺少任一项时只保存已提供输入并提示缺失项，不开始任何内容提取、识别或诊断。
- 截图识别结果必须先经过用户确认，原始识别结果与用户确认内容分开保存；未确认内容不得进入作品深挖、检索或优化 Demo。

## 事实与证据

- 只使用用户已提供、用户已确认或产品明确允许读取的可见资料。
- 联网资料必须保存来源、URL、检索时间和引用关系；无法验证来源时不得写成确定事实。
- 未确认、缺失或无法辨认的信息标记为未知，不使用常识补全。
- 主要结论关联输入证据；无法说明来源时，不生成确定结论。
- 将数据结果表达为方向性证据，不把相关性写成因果。
- 输出知识引用、证据强度、待验证假设和不确定性。

## 知识与冲突

按以下顺序使用知识：当前有效创作地图 → 当前账号已确认案例 → 产品初始知识 → 用户本次要求。发生冲突时，比较场景具体性、更新时间和证据强度；无法消解时保留并展示冲突，不静默合并成绝对规则。

只有用户确认的创作地图和学习案例才能作为账号正式知识。未确认草稿不得进入后续正式检索。

## 安全与原创

- 不生成抄袭、搬运、刷量、虚假互动或规避平台审核建议。
- 不复制参考内容的独特句式、故事、图片构图、文字排版或可识别内容顺序。
- 不编造身份、地点、预算、家庭、健康、专业背景、使用经历、产品功效或数据结果。

## 公共输出

每次输出至少包含：

- `status`
- `profile_id`或脱敏引用
- `version_id`
- `evidence`
- `unknowns`
- `uncertainties`
- `cited_knowledge`
- `user_confirmation_required`

模型生成失败、字段缺失或状态不允许时，返回可操作的错误原因，不生成部分确定性结论。
